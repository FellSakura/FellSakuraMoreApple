# MoreApple

![Downloads](https://cf.way2muchnoise.eu/1724064.svg)
![curseforge](https://cf.way2muchnoise.eu/versions/1724064.svg)  
Do you think there are too few types of apples or that they aren’t very useful in the vanilla version of Minecraft? This
mod adds several apple variants, such as diamond apples; eating a diamond apple grants a better buff than a golden
apple.  
Of course, this mod also restores the recipe for enchanting golden apples.

# Future Plans

Add more varieties of apples and charming apples.
